# 프록시 안내

[README로 돌아가기](../README.md)

## 설정과 로그인

1. 로그인 전에는 홈 화면의 **로그인** 옆 **프록시 설정**, 로그인 후에는 **설정 → 계정 및 연동 → 프록시**로 이동합니다.
2. 본인의 WireGuard `.conf`를 가져오거나 HTTP·HTTPS·SOCKS5 서버 정보를 입력합니다.
3. 연결 방식을 저장하고 사용을 켠 뒤, 앱을 완전히 종료하고 다시 엽니다.
4. 프록시 화면에서 연결을 확인한 뒤 로그인·곡 재생을 진행합니다.

WireGuard는 표준 단일 피어 설정을 사용합니다. `AllowedIPs`에 `0.0.0.0/0`, `DNS`에는 숫자 IP가 필요합니다. 개인키와 프록시 비밀번호는 기기의 Keychain에 저장합니다. 사용자 자신의 프로필이 필요하며 개인 설정은 소스·IPA에 포함하지 않습니다.

## 적용 범위

| 경로 | 처리 |
|---|---|
| 앱 내부 URLSession API 요청 | 설정한 프록시 적용 |
| 캐시를 거치는 HTTP 오디오 재생 | 설정한 프록시 적용 |
| 프록시를 켠 실행의 음원 다운로드 | 앱 내부 전송 경로로 프록시 적용 |
| Google 로그인 웹 화면 | WKWebView 생성 전 해당 데이터 저장소에 별도 적용 |
| 시스템 AVFoundation의 직접 HLS·커버 영상, 다른 WebKit 저장소, SMB | 앱 내부 프록시 적용 범위 밖 |

Google 로그인은 URLSession 설정을 그대로 상속하지 않으므로 로그인에 쓰는 WebKit 데이터 저장소에도 별도로 적용합니다. 프록시 구성에 실패하면 로그인 페이지를 열지 않고 안내를 표시합니다.

앱 내부 프록시는 시스템 VPN 프로필이나 Network Extension을 만들지 않습니다. 프록시를 적용한 URLSession과 로그인 웹 화면은 연결 실패 시 직접 연결로 전환하지 않습니다. 적용 범위 밖의 요청은 기기 자체 연결을 사용할 수 있습니다.

WireGuard 모드의 음원 호스트 DNS 조회는 터널 안에서 처리합니다. 서버 Endpoint가 호스트 이름이면 터널을 만들기 전에 기기 DNS로 한 번 조회합니다.

## 다운로드

프록시를 켠 실행에서는 주소 조회·재생과 같은 앱 내부 전송 경로로 다운로드합니다. 앱 프로세스가 실행되는 동안 동작하므로 다운로드가 끝날 때까지 앱을 열어 두세요. 완료된 범위는 체크포인트로 보관합니다.

프록시를 사용하지 않을 때는 기존 시스템 백그라운드 다운로드 경로를 사용합니다.

## 연결 진단

- 프록시 화면의 국가 확인과 함께 실제 로그인·곡 재생도 확인합니다. 국가 확인만으로 모든 전송 경로의 성공 여부를 판단할 수는 없습니다.
- 잠금화면·다이나믹 아일랜드에서 앱이 열리지 않으면 프록시 화면의 **앱 열기 진단**을 확인합니다. 실제 설치된 번들 ID를 Now Playing 연결 대상으로 지정하며, `application-identifier`는 진단용으로만 읽습니다.
- 홈 위젯에 곡이 표시되지 않으면 **설정 → 진단 → 위젯 연결**에서 공유 저장소 상태를 확인합니다. 앱과 위젯이 같은 App Group에 접근할 수 있어야 합니다.
- 여러 곡의 전송·재생 문제는 **설정 → 진단 → 전체 로그 기록**으로 수집할 수 있습니다. 로그 기록은 기본 꺼짐입니다.

앱 열기 보완에는 비공개 MediaRemote API를 사용하므로 iOS·서명 환경에 따라 동작이 달라질 수 있습니다. 앱 열기 진단에서 해당 패치를 끌 수 있습니다.

## 개발자 참고

앱 내부 WireGuard 전송 경로는 다음과 같습니다.

```text
URLSession API / HTTPAudioSource / 앱 내부 다운로드
  → 인증된 로컬 SOCKS5·CONNECT
  → wireguard-go + gVisor 사용자 공간 네트워크
  → 사용자가 지정한 WireGuard 서버
```

`scripts/make-ipa.sh`는 엔진 준비를 포함합니다. Xcode에서 직접 빌드할 경우 대상 플랫폼에 맞는 엔진 아카이브를 먼저 만듭니다.

```sh
# 실기기
MIN_IOS=17.0 bash WireGuard/build-ios.sh
open BitChord.xcworkspace

# 시뮬레이터
SDK_NAME=iphonesimulator bash WireGuard/build-ios.sh
```

관련 구성 요소의 라이선스는 [WireGuard 고지](../WireGuard/THIRD_PARTY_LICENSES.txt)를 참고하세요.
